# Caviar

Caviar is an AI-powered career intelligence and candidate performance platform.

This repository is being built in phases. Phase 1 (current) establishes the
backend repository foundation only: FastAPI application factory, structured
logging, centralized exception handling, request correlation IDs, database
engine/session scaffolding, and an empty Alembic migration environment.

No Supabase schema, authentication, resume, Gemini, interview, speech, or
LaTeX functionality exists yet. No frontend exists yet. See
`CAVIAR_PHASE_0_ARCHITECTURE.md` (project files) for the approved
architecture baseline this repository follows.
